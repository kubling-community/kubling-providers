# Support

## Community support

Use GitHub Discussions for usage questions, provider design discussions and
general help. Use GitHub Issues for reproducible bugs and focused feature
requests.

When reporting a problem, include the affected provider or SDK version,
configuration with secrets removed, relevant logs and the smallest reproducible
example you can provide.

This project is pre-1.0 and community support is provided on a best-effort
basis without a response-time or compatibility SLA. The latest release is the
supported starting point for troubleshooting.

## Security

Do not report vulnerabilities through public Discussions or Issues. Follow
[`SECURITY.md`](SECURITY.md) to disclose them privately.
